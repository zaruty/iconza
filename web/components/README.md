# Components

## `ui/` — Design system

Componentes puros, sem Supabase. Portar estilos de `iconza-base.css`.

Prioridade: `Button`, `Card`, `Tag`, `LoadingOverlay`, `PageHeader`, `Icon`.

## `layout/` — Shell

Equivalente a `iconza-layout.js` + `iconza-sidebar.js`:

- `app-shell.tsx`
- `sidebar.tsx` (drawer mobile-first)
- `topbar.tsx`

## `brain/`

Equivalente a `iconza-brain.js` → `brain-canvas.tsx` (client component).
